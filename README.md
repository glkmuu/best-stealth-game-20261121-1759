Ghostlight Heist is a top-down 2D stealth game: slip through a museum at night across 4 levels (The Archive, The Gallery, The Vault, The Rooftop), dodge guard vision cones, sweeping cameras, laser grids and listening dogs, throw coins to distract patrols, grab keycards to open locked doors, hack security terminals to kill the cameras, and reach the exit unseen. Darkness, lamp pools, a flashlight cone and a live minimap make safe routes readable at a glance.

## Run it

```sh
node serve.ts
```
(open http://localhost:8080)

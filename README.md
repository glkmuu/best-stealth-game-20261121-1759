**Ghostlight Heist** — a top-down 2D stealth game. You are a thief infiltrating a museum at night across three levels (The Archive, The Gallery, The Vault): sneak past patrolling guards with real vision cones and line-of-sight checks, hide behind crates and pillars, dodge sweeping security cameras and a guard dog that hears running, steal every artifact, and reach the exit unseen. Detection builds from calm to suspicious to alerted, light pools and running get you spotted faster, and finishing a level fast and never detected earns the ghost bonus and three stars. All art is procedural canvas drawing and all sound is synthesized WebAudio — no external assets, no network requests.

## Run it

```sh
node serve.ts
```
(open http://localhost:8080)

## Controls

WASD / arrows — move · Shift — sneak · Space — run (loud!) · E — steal artifact · H — hint · R — restart level · P — pause · M — mute
